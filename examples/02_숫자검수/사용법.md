# 02 보고서 숫자를 원본 CSV와 대조하기

- 쓰는 스킬: `doc-data-audit`
- 추천 팀: 전 팀
- 준비 파일: 주간품질보고_week42_검토본.md (일부러 틀린 숫자를 넣은 보고서), 테스트결과_week42_전체.csv

## 붙여 넣을 요청

1.
```
doc-data-audit 스킬로 주간품질보고_week42_검토본.md의 숫자가 테스트결과_week42_전체.csv와 맞는지 하나씩 다시 계산해서 대조해 줘. 결과는 판정, 재계산 값, 틀린 위치로 정리해 줘. 문서는 고치지 마.
```

## 이렇게 나오면 맞습니다

- B라인 평균 수율: 보고서 99.17% → 재계산 99.07%로 불일치
- 불량(Bin 2~8) 합계: 보고서 2,246개 → 재계산 2,264개로 불일치
- 나머지 숫자(로트 수, 전체 수량, 전체 수율, 미달 로트 3개)는 일치

## 우리 업무에 쓰려면

보고서를 팀장님께 올리기 전에 이 요청을 습관처럼 붙이면 됩니다. 엑셀·PPT·워드 어느 형식이든 원본 파일과 함께 첨부하면 됩니다.
