# 10 내 반복 업무를 스킬로 만들기

- 쓰는 스킬: `meta-skill-builder`, `meta-skill-tester`
- 추천 팀: 전 팀
- 준비 파일: 없음 (질문에 답하면서 진행)

## 붙여 넣을 요청

1.
```
meta-skill-builder 스킬로 내 반복 업무를 스킬로 만들고 싶어. 나에게 질문을 하나씩 하고, 답을 받으면 SKILL.md 초안을 보여 줘. 아직 저장하지는 마.
```

2.
```
meta-skill-tester 스킬로 방금 만든 초안을 테스트할 요청 예시 3개와 확인 기준을 만들어 줘.
```

## 이렇게 나오면 맞습니다

- 입력 파일, 결과 양식, 반복 주기, 하지 말 것을 묻는 질문
- 이름이 영문 소문자와 하이픈인 SKILL.md 초안
- 테스트 요청과 통과 기준 표

## 우리 업무에 쓰려면

예: AE기술 "공정별 불량원인 요약", TEST "HW 인벤토리 송부 문서", sig pm "표준문서 검토기한 목록". 회사 실제 데이터 대신 파일 형식과 절차만 설명하십시오.
