# 09 AI 투 고객 회신 메일 다듬기

- 쓰는 스킬: `ai-slop-reviewer`, `fact-estimate-check`
- 추천 팀: 영업, 고객 대응, 품질
- 준비 파일: 고객회신_초안.txt (AI가 쓴 듯한 과장 표현과 원인 단정이 섞인 메일, 가상)

## 붙여 넣을 요청

1.
```
ai-slop-reviewer 스킬로 고객회신_초안.txt의 과장 표현과 AI 티 나는 문장을 고쳐 줘. 이어서 fact-estimate-check 스킬로 원인을 단정한 문장도 점검해서 확인 중인 내용으로 바꿔 줘. 메일은 보내지 말고 화면에만 보여 줘.
```

## 이렇게 나오면 맞습니다

- "혁신적인", "완벽하게 규명", "절대 발생하지 않을 것" 같은 표현이 사라짐
- 원인 문장이 "현재 분석 중이며, 결과는 ~까지 회신드리겠습니다" 형태로 바뀜
- 메일을 보내지 않고 수정본만 보여 줌

## 우리 업무에 쓰려면

실제 고객 회신은 사내 승인 절차를 거친 뒤 사람이 보냅니다.
