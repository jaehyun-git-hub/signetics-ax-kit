# 04 임원 보고 한 장 만들기

- 쓰는 스킬: `collab-exec-summary`, `doc-pptx`
- 결과물: 본부장 보고용 PPT 1장 (숫자 카드 + 상황 · 의미 · 다음 조치)
- 준비 파일: 품질실적_2026-10_주차별.csv, 회의메모.txt

## 붙여 넣을 요청

```
collab-exec-summary 스킬로 첨부한 10월 품질실적과 11/2 품질회의 메모를 본부장 보고용으로 요약해 줘.
무슨 일이 있었는지, 그래서 무엇이 문제인지, 다음에 무엇을 할지 순서로 각각 2줄 이내로 써 줘. 원인은 확인 중이라고 써 줘.
```

요약을 확인한 뒤 이어서 붙여 넣습니다.

```
doc-pptx 스킬로 이 요약을 PPT 한 장으로 만들어 줘. 위쪽에 숫자 카드 3개(10월 수율, 미달 주차·라인, 진행 중 조치), 아래쪽에 상황 · 의미 · 다음 조치를 3단으로 넣어 줘. 제목은 결론 한 문장으로.
```

## 이렇게 나오면 맞습니다

- 숫자: 10월 수율 약 99.16%, 43주 C라인 98.95%(목표 미달), 미달 로트 B02·C01
- 다음 조치: C01·C02 단면 분석(AE, 11/6), 테스트 프로그램 리비전 확인(TEST, 금주), WB-02 PM(다음 주)
- 회의 메모에 없는 원인이나 담당자를 새로 만들지 않음

## 해 보면 좋은 추가 요청

```
같은 내용을 팀장 보고용으로 바꿔서, 숫자를 조금 더 자세히 넣은 버전도 만들어 줘.
```
