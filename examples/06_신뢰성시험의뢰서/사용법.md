# 06 신뢰성 시험 의뢰서 워드로 만들기

- 쓰는 스킬: `doc-docx`
- 추천 팀: Rel/Cal, AE기술
- 준비 파일: 의뢰_메모.txt (시험 조건 메모, 가상)

## 붙여 넣을 요청

1.
```
doc-docx 스킬로 의뢰_메모.txt 내용을 신뢰성 시험 의뢰서 워드 파일로 만들어 줘. 표는 시험 항목·조건·시료 수·중간 판정·판정 기준 순서로 정리하고, 메모에 없는 값은 빈칸으로 두고 (담당자 입력)이라고 써 줘. 파일 이름은 신뢰성시험의뢰서_SG261021C01.docx로 해 줘.
```

## 이렇게 나오면 맞습니다

- 시험 항목 4개(전처리, TC, HTS, uHAST)가 표로 정리됨
- 의뢰자처럼 메모에 없는 칸은 (담당자 입력)
- 희망 완료일 2026-12-18과 시료 입고일이 그대로 들어감

## 우리 업무에 쓰려면

우리 부서 의뢰서 양식(docx)을 첨부하고 "이 양식의 칸에 채워 줘"라고 하면 양식 모양을 그대로 지킵니다.
