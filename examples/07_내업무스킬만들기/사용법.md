# 07 내 반복 업무를 스킬로 만들기

- 쓰는 스킬: `meta-skill-builder`, `meta-skill-tester`
- 결과물: 내 업무용 SKILL.md 초안과 테스트 요청 예시
- 준비 파일: 없음 (질문에 답하면서 진행)

## 붙여 넣을 요청

```
meta-skill-builder 스킬로 내 반복 업무를 스킬로 만들고 싶어. 나에게 질문을 하나씩 하고, 답을 받으면 SKILL.md 초안을 보여 줘.
결과 파일이 PPT면 doc-pptx의 기본 디자인 키트를, 워드면 doc-docx의 기본 디자인 키트를 쓰도록 절차에 넣어 줘. 아직 저장하지는 마.
```

```
meta-skill-tester 스킬로 방금 만든 초안을 테스트할 요청 예시 3개와 확인 기준을 만들어 줘.
```

## 이렇게 나오면 맞습니다

- 입력 파일, 결과 양식, 반복 주기, 하지 말 것을 묻는 질문
- 이름이 영문 소문자와 하이픈인 SKILL.md 초안
- 테스트 요청과 통과 기준 표

## 업무 예시

공정별 불량 원인 월간 요약, 고객 회신 메일 초안, HW 인벤토리 송부 문서, 표준문서 검토 기한 목록. 회사 실제 데이터 대신 파일 형식과 절차만 설명하십시오.
