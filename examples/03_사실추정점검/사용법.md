# 03 경위서 문장에서 사실과 추정 나누기

- 쓰는 스킬: `fact-estimate-check`
- 추천 팀: AE기술, 품질, 고객 대응 담당
- 준비 파일: 불량경위_메모.txt (원인을 단정한 문장이 섞인 초안)

## 붙여 넣을 요청

1.
```
fact-estimate-check 스킬로 불량경위_메모.txt를 점검해 줘. 문장마다 [사실]과 [추정]으로 나누고, 원인을 단정한 문장은 원인 후보와 확인 방법으로 고쳐 줘. 확인 담당은 (담당자 입력)으로 비워 줘.
```

## 이렇게 나오면 맞습니다

- 수율 96.9%, Bin5 100개 문장은 [사실] — 다만 근거 CSV가 첨부되지 않았으면 "근거 미확인"으로 표시
- "범프 접합 불량 때문이다", "온도 관리 미흡이 근본 원인이다"는 [추정]으로 바뀌고 확인 방법(단면 분석, 설비 온도 기록 조회)이 붙음
- "조치를 완료했다", "재발하지 않을 것이다"는 근거 기록이 없으면 [추정] 또는 확인 필요로 표시

## 우리 업무에 쓰려면

고객에게 나가는 메일이나 8D 초안을 보내기 전에 같은 요청을 붙이면 됩니다. 근거 데이터 파일을 함께 첨부하면 숫자까지 다시 계산해 줍니다.
