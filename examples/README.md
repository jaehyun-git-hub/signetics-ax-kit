# 활용 예제

시그네틱스 AX 키트를 설치한 뒤 따라 하는 예제 7개입니다. 모든 데이터는 교육용 가상 데이터이며 실제 시그네틱스 숫자가 아닙니다.

Claude 앱에서 새 대화를 열고, 예제 폴더의 파일을 첨부한 다음, `사용법.md`의 요청을 붙여 넣으면 됩니다. 요청에 스킬 이름을 넣어 두었기 때문에 키트의 스킬이 쓰입니다.

| 번호 | 예제 | 결과물 | 쓰는 스킬 |
|---|---|---|---|
| 01 | [10월 품질 리뷰 PPT](01_월간품질리뷰_PPT/사용법.md) | PPT 8~9장 | doc-pptx |
| 02 | [같은 내용을 HTML 발표 슬라이드로](02_발표슬라이드_HTML/사용법.md) | HTML 슬라이드 | doc-html-slide |
| 03 | [고객 불량 8D 보고서](03_고객불량_8D보고서/사용법.md) | 워드 | doc-docx, fact-estimate-check |
| 04 | [임원 보고 한 장](04_임원보고_한장/사용법.md) | PPT 1장 | collab-exec-summary, doc-pptx |
| 05 | [10월 품질 대시보드](05_품질대시보드/사용법.md) | 대시보드 HTML | data-visualizer |
| 06 | [설비 가동률 엑셀 리포트](06_설비가동률_엑셀/사용법.md) | 엑셀 3시트 | data-explorer, doc-xlsx |
| 07 | [내 반복 업무를 스킬로](07_내업무스킬만들기/사용법.md) | SKILL.md 초안 | meta-skill-builder, meta-skill-tester |

01·02·04·05는 같은 10월 데이터를 써서, 결과물마다 숫자가 같은지 비교해 볼 수 있습니다.
