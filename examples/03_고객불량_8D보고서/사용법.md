# 03 고객 불량 8D 보고서(1차 회신) 워드로 만들기

- 쓰는 스킬: `doc-docx` (디자인 키트 doc_kit.py 포함), `fact-estimate-check`
- 결과물: 고객 회신용 8D 보고서 워드 파일. 문장마다 [사실]·[추정] 표시, 원인은 후보와 확인 방법으로 정리
- 준비 파일: 고객불량접수_CQ-2610-07.txt, 내부분석메모_SG261013C02.txt

## 붙여 넣을 요청

```
doc-docx 스킬로 첨부한 고객 불량 접수서와 내부 분석 메모를 가지고 고객사 K에 보낼 8D 보고서 1차 회신 초안을 워드로 만들어 줘.

- D1 팀 구성, D2 문제 정의, D3 임시 조치, D4 근본 원인, D5~D8 다음 단계 순서로
- 맨 위에 문서 번호·접수일·작성일·상태를 한 줄로, 그 아래 "확인 필요" 안내 상자
- fact-estimate-check 스킬 기준으로 근거가 있는 내용은 [사실]과 근거 파일, 확인 전인 내용은 [추정]과 확인 방법으로 써 줘
- 원인은 단정하지 말고 원인 후보로만, 담당자와 일정은 (담당자 입력)으로 비워 줘
- 마지막에 작성·검토·승인 서명란
```

## 이렇게 나오면 맞습니다

- [사실]: 고객 검사 1,200개 중 12개 불량, 출하 전 수율 96.9%, Bin5 100개, 같은 날 C01·C03은 기준 이상
- [추정]: 범프 접합 불량, 자재 로트 변경(10/12), 테스트 프로그램 리비전 변경(10/10) — 각각 확인 방법이 붙음
- "리플로 온도 기록이 관리 범위 안" 문장은 기록 파일이 없으므로 [추정]이나 "기록 첨부 시 사실" 같은 표시
- 담당자 이름(김 책임, 이 선임 등)은 메모에 "공식 지정 전"이라고 되어 있으므로 확정해서 쓰지 않음
