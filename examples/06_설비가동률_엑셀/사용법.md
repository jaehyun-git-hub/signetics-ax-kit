# 06 설비 가동률 엑셀 리포트 만들기

- 쓰는 스킬: `data-explorer`, `doc-xlsx`
- 결과물: 요약 시트(숫자 카드·차트), 설비별 일자표, 점검 필요 목록으로 나눈 엑셀 파일
- 준비 파일: 설비가동_2026-10.csv (설비 10대 10월 가동 기록, 가상. 일부러 빠진 값과 입력 오류를 넣음)

## 붙여 넣을 요청

```
data-explorer 스킬로 첨부한 설비가동 파일을 먼저 점검해 줘. 빠진 값, 음수 같은 이상한 값, 휴무일을 찾아서 목록으로 보여 주고 아직 고치지는 마.
```

점검 결과를 확인한 뒤 이어서 붙여 넣습니다.

```
doc-xlsx 스킬로 엑셀 리포트를 만들어 줘.
- 휴무일은 빼고, 빠진 값과 입력 오류는 표시만 해 둔 채 계산
- 설비별 월간 가동률 = 가동시간 ÷ 계획시간 × 100 (수식으로 넣기)
- 시트 1 "요약": 위쪽에 전체 가동률·최저 설비·고장정지 합계 숫자 카드, 아래에 설비별 가동률 막대 차트
- 시트 2 "설비별 일자표": 설비 × 일자 가동률 표, 85% 미만 셀은 빨간 바탕
- 시트 3 "점검 필요": 빠진 값·입력 오류 목록
- 머리글 행은 남색 바탕 흰 글자, 틀 고정, 열 너비 맞춤
```

## 이렇게 나오면 맞습니다

- 고장정지 -15분 같은 입력 오류와 빠진 행이 점검 필요 시트에 나옴
- 가동률이 숫자가 아니라 수식으로 들어가 있어 셀을 누르면 계산식이 보임
- 85% 미만 셀이 빨간색

```
가동률이 가장 낮은 설비 2대의 고장정지 원인을 확인하려면 어떤 기록이 더 필요한지 정리해 줘.
```
