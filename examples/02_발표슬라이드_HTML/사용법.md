# 02 같은 내용을 HTML 발표 슬라이드로 만들기

- 쓰는 스킬: `doc-html-slide`
- 결과물: 브라우저에서 바로 열리는 발표 슬라이드 HTML 1개 (키보드로 넘기기, 전체 화면, 발표자 노트, PDF 인쇄)
- 준비 파일: 품질실적_2026-10_주차별.csv, 조치현황_2026-10.csv

PPT보다 디자인이 자유로워서 차트·숫자 카드가 더 크고 선명하게 나옵니다. 사내 공유 화면이나 모니터 발표에 좋습니다.

## 붙여 넣을 요청

```
doc-html-slide 스킬로 첨부한 10월 품질실적과 조치현황으로 발표 슬라이드 8장을 HTML로 만들어 줘.
테마는 light-report로 하고, 장마다 제목은 결론 문장으로 써 줘.
요약 숫자 카드, 주차별 라인 수율 추이(목표 99.0% 기준선), 불량 유형 차트, C라인 기능 불량 추이, 조치 현황, 11월 계획이 들어가게 해 줘.
차트는 SVG로 그려서 숫자가 정확하게 보이게 하고, 숫자가 있는 장에는 출처를 적어 줘.
발표자 노트에는 장마다 말할 내용을 2문장으로 써 줘.
```

## 이렇게 나오면 맞습니다

- 파일을 열면 첫 장이 화면 가득 나오고 → 키로 넘어감
- 차트의 숫자가 01 예제 PPT와 같음 (10월 수율 약 99.16%, 43주 C라인 98.95%)
- N 키로 발표자 노트가 보임

## 해 보면 좋은 추가 요청

```
테마를 warm-editorial로 바꿔서 한 번 더 만들어 줘. 두 개를 나란히 비교해 볼게.
```
```
같은 원고로 편집 가능한 PPTX도 만들어 줘.
```
