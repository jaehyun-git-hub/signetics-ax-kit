# 05 10월 품질 대시보드 만들기

- 쓰는 스킬: `data-visualizer`
- 결과물: 브라우저에서 여는 대시보드 HTML 1개 (숫자 카드, 추이 차트, 불량 유형, 공정별 접수 건, 라인 선택 필터)
- 준비 파일: 품질실적_2026-10_주차별.csv, 불량접수_2026-10.csv

## 붙여 넣을 요청

```
data-visualizer 스킬로 첨부한 두 파일을 가지고 10월 품질 대시보드를 HTML 한 파일로 만들어 줘.

- 맨 위: 10월 수율, 테스트 수량, 불량 수량, 불량 접수 건수 숫자 카드
- 주차별 라인 수율 추이 꺾은선 (목표 99.0% 기준선)
- 불량 유형(Bin2~8) 막대, 공정별 불량 접수 건수 막대
- 라인 A·B·C를 고르면 차트가 그 라인만 보이는 필터
- 흰 바탕, 깔끔한 카드형 배치, 회의실 화면에서 보이도록 글자 크게
숫자는 파일에서 계산하고, 각 차트 아래에 출처 파일 이름을 적어 줘.
```

## 이렇게 나오면 맞습니다

- 숫자 카드의 10월 수율이 01·02 예제와 같음 (약 99.16%)
- 라인 필터를 바꾸면 차트가 바뀜
- 인터넷이 막힌 PC에서 열 경우 차트 라이브러리를 못 불러올 수 있음 — 그때는 "인터넷 없이 열리게 다시 만들어 줘"라고 요청

## 해 보면 좋은 추가 요청

```
대시보드 맨 아래에 기준 미달 주차·라인 목록 표를 넣고, 미달 값은 빨간색으로 표시해 줘.
```
