# 07 회의 메모로 회의록과 할 일 표 만들기

- 쓰는 스킬: `collab-meeting`
- 추천 팀: 전 팀
- 준비 파일: 회의메모.txt (주간 품질회의 메모, 가상)

## 붙여 넣을 요청

1.
```
collab-meeting 스킬로 회의메모.txt를 회의록으로 정리해 줘. 결정 사항, 확인할 일, 담당·기한 표로 나누고, 메모에 담당이나 기한이 없으면 빈칸으로 둬 줘.
```

## 이렇게 나오면 맞습니다

- 결정: C01·C02 시료 각 5개 단면분석 의뢰 (AE 이, 11/6까지)
- 확인할 일: Bin5 테스트 프로그램 리비전 확인 (TEST 박, 금주)
- "원인 모름" 상태가 그대로 유지되고, 원인을 새로 만들지 않음
