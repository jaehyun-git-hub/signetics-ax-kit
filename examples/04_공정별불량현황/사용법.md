# 04 공정별 불량 현황 보고서와 차트 만들기

- 쓰는 스킬: `collab-status-report`, `data-visualizer`
- 추천 팀: AE기술, 품질
- 준비 파일: 불량접수_2026-10.csv (10월 불량 접수 60건, 가상)

## 붙여 넣을 요청

1.
```
collab-status-report 스킬로 불량접수_2026-10.csv를 공정별·불량유형별로 정리해서 10월 불량 현황 보고서를 써 줘. 숫자는 표로, 공정별 합계와 상위 불량유형을 보여 주고, 원인은 쓰지 말고 확인할 항목만 적어 줘.
```

2.
```
data-visualizer 스킬로 공정별 불량 수량 막대그래프와 주차별 접수 건수 추이 그래프를 만들어 줘.
```

## 이렇게 나오면 맞습니다

- 공정 8개별 접수 건수와 불량 수량 합계 표
- 상위 불량유형 목록과 주차별 추이 그래프
- "원인"은 비워 두고 "확인할 항목"으로만 정리

## 우리 업무에 쓰려면

우리 팀 불량 접수 양식(엑셀)을 그대로 첨부해도 됩니다. 열 이름이 달라도 먼저 구조를 살펴본 뒤 정리합니다.
