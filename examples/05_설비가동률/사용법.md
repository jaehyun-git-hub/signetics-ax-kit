# 05 설비 가동률 집계와 데이터 점검

- 쓰는 스킬: `data-explorer`, `doc-xlsx`
- 추천 팀: SIGALL, 생산
- 준비 파일: 설비가동_2026-10.csv (설비 10대 10월 가동 로그, 가상 — 일부러 누락값과 입력 오류를 넣음)

## 붙여 넣을 요청

1.
```
data-explorer 스킬로 설비가동_2026-10.csv를 먼저 살펴봐 줘. 빠진 값, 음수 같은 이상한 값, 휴무일을 찾아서 목록으로 보여 주고, 아직 고치지는 마.
```

2.
```
휴무일은 빼고, 누락값과 입력 오류는 표시만 해 둔 채로 설비별 월간 가동률(가동시간 ÷ 계획시간 × 100)을 계산해 줘. doc-xlsx 스킬로 요약 시트, 설비별 일자표, 점검 필요 목록 시트로 나눈 엑셀을 만들어 줘.
```

## 이렇게 나오면 맞습니다

- 로그 누락 행과 고장정지 -15분 같은 입력 오류가 점검 필요 목록에 나옴
- 설비 10대의 가동률 표와 계산식 설명
- 엑셀 시트 3개: 요약, 설비별 일자표, 점검 필요 목록
