# 01 10월 품질 리뷰 PPT 만들기

- 쓰는 스킬: `doc-pptx` (디자인 키트 deck_kit.js 포함)
- 결과물: 경영회의용 품질 리뷰 PPT 8~9장 (표지, 요약 숫자 카드, 주차별 추이 차트, 불량 유형 차트, 라인별 표, 조치 현황, 다음 달 계획)
- 준비 파일: 품질실적_2026-10_주차별.csv, 조치현황_2026-10.csv

## 붙여 넣을 요청

새 대화를 열고 파일 2개를 첨부한 뒤 붙여 넣습니다.

```
doc-pptx 스킬로 첨부한 10월 품질실적과 조치현황 파일을 가지고 경영회의용 "10월 품질 리뷰" PPT를 만들어 줘.

구성은 이렇게 해 줘.
1. 표지
2. 요약: 10월 수율, 테스트 수량, 가장 낮았던 주차·라인, 조치 진행 현황을 숫자 카드 4개로
3. 주차별 라인 수율 추이 꺾은선 차트 (목표 99.0% 기준선 포함)
4. 불량 유형(Bin2~8)별 수량 막대 차트
5. 가장 많이 늘어난 불량 유형 하나를 주차별로 보여 주는 차트
6. 라인별 요약 표 (투입, 양품, 수율, 최저 주차)
7. 조치 현황 (상태 표시 포함)
8. 11월 계획

장마다 제목은 그 장의 결론을 한 문장으로 써 줘. 숫자는 파일에서 다시 계산하고, 출처 파일 이름을 장마다 적어 줘. 원인은 단정하지 말고 확인 중이라고 써 줘.
```

## 이렇게 나오면 맞습니다

- 10월 전체 수율 약 99.15%, 목표 99.0% 달성
- 가장 낮은 주차·라인은 43주 C라인 98.95%
- C라인 Bin5 기능 불량이 42주 185개로 다른 주보다 많음
- 표지와 마지막 장은 어두운 남색, 나머지는 흰 바탕에 파란 띠. 미달 값만 빨간색
- 차트는 PPT 안에서 데이터를 고칠 수 있는 편집 가능한 차트

## 해 보면 좋은 추가 요청

```
3장 차트 옆에 '읽는 법' 상자를 넣고 요점 3줄을 적어 줘.
```
```
같은 덱을 9월과 비교하는 장을 하나 넣고 싶어. 9월 데이터가 없으니 어떤 파일이 필요한지만 알려 줘.
```
