# 01 주간 품질보고 PPT 만들기

- 쓰는 스킬: `weekly-quality-report`
- 추천 팀: AE기술, TEST, SIGALL
- 준비 파일: 테스트결과_week42_전체.csv, 테스트결과_week43_전체.csv, 주간품질보고_양식.pptx

## 붙여 넣을 요청

1.
```
weekly-quality-report 스킬로 첨부한 테스트결과_week42_전체.csv의 주간 품질보고 PPT를 만들어 줘. 양식은 첨부한 주간품질보고_양식.pptx를 써 줘.
```

2.
```
같은 방법으로 테스트결과_week43_전체.csv도 만들고, 42주차와 43주차 라인별 평균 수율을 표로 비교해 줘. 파일은 만들지 마.
```

## 이렇게 나오면 맞습니다

- 42주차: 라인 평균 A 99.12% · B 99.07% · C 98.99%, 기준 미달 로트 3개, 검산 243,000개 일치
- 43주차: 라인 평균 A 99.15% · B 98.97% · C 98.96%, 기준 미달 로트 2개, 검산 237,400개 일치
- 5장 조치 사항이 [사실]과 [추정]으로 나뉘고, 담당 칸은 (담당자 입력)으로 비어 있음

## 우리 업무에 쓰려면

우리 팀 양식 PPT를 첨부하고 같은 요청을 해 보세요. 열 이름이 다른 CSV라면 "열 이름이 다르면 먼저 어떤 열을 쓸지 물어봐 줘"를 붙입니다.
