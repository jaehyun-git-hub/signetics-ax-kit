# 디자인 테마 선택

이 키트에는 외부 브랜드 디자인 시스템을 넣지 않았습니다. 사용자 회사의 브랜드 가이드(색, 로고, 서체)가 있으면 그것을 먼저 쓰고, 없으면 [themes.md](themes.md)의 기본 테마 3종 가운데 고릅니다.

| 상황 | 테마 |
|---|---|
| 회의실 프로젝터, 품질·생산 보고 | `light-report` |
| 경영진 보고, 읽는 자료 | `warm-editorial` |
| 데이터 공유, 화면 공유 발표 | `dark-engineering` |

특정 회사의 브랜드 디자인을 그대로 따라 한 자료는 만들지 않습니다.
