# 사실·추정 점검

## 기준
- [사실]: 첨부 파일·데이터·기록·고객 접수서로 확인되는 내용. 수량, 수율, 날짜, 증상, 측정값.
- [추정]: 아직 확인하지 않은 내용. 원인 후보, 영향 범위 짐작, 재발 가능성, 다른 로트·설비로의 확대 가능성.
- 판단 질문: "이 문장을 증명할 파일이나 기록을 가리킬 수 있는가?" 가리킬 수 있으면 사실, 없으면 추정.

## 절차
1. 점검할 문서와 근거 자료(CSV, 엑셀, 측정 기록, 접수서 등)를 확인한다. 근거 자료가 없으면 수치 문장도 "근거 미확인"으로 표시하고, 필요한 자료를 요청한다.
2. 문장을 하나씩 나눠 표로 정리한다. 열: 번호, 원문, 구분([사실]/[추정]), 근거(파일 이름·위치) 또는 확인 방법.
3. 숫자 문장은 근거 자료에서 다시 계산해 맞는지 확인한다. 다르면 "불일치"로 표시하고 원본 값을 적는다.
4. 원인을 단정한 문장("~때문이다", "~가 원인이다", "~로 확인되었다"인데 근거가 없는 경우)을 찾아 다음 형식으로 고친 문장을 제안한다.
   - 원인 후보: ~ / 확인 방법: ~ / 확인 담당: (담당자 입력)
5. 고친 문서 전체를 보여 주고, 모든 문장 앞에 [사실] 또는 [추정]을 붙인 버전을 함께 제공한다.
6. 끝에 요약을 붙인다: 사실 문장 수, 추정 문장 수, 단정 문장 수와 고친 위치, 근거 미확인 수치.

## 하지 말 것
- 원문 파일을 직접 덮어쓰기. 고친 내용은 새 파일이나 화면으로만 제공한다.
- 담당자, 일정, 확인 결과를 지어내기
- 추정 문장을 지우기. 추정은 [추정]으로 표시한 채 그대로 두고, 확인 방법을 붙인다.
- 고객사 이름, 실제 공정 조건처럼 외부로 나가면 안 되는 정보를 새로 추가하기
